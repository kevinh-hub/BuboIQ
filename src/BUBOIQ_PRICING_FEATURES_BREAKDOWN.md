## 🏥 Healthcare (HIPAA) Features Breakdown

**Available In**: Team tier only (or with Security & Compliance Pack)

### Automatic PHI Detection
- Pattern-based scanning for:
  - Social Security Numbers (SSN)
  - Medical Record Numbers (MRN)
  - Date of Birth (DOB)
  - Phone numbers
  - Email addresses
  - Credit card numbers
- Confidence scoring (Low/Medium/High)
- Real-time detection in tickets, chat, notes
- False positive marking

### Automatic PHI Redaction
- Pattern replacement (***-**-1234)
- Audit trail of all redactions
- Approval workflows
- Redaction preview before commit
- Immutable redaction logs

### Breach Notification Workflows
**7-Step Automated Workflow**:
1. **Detection & Assessment**: Identify scope and severity
2. **Containment**: Immediate actions to limit exposure
3. **Investigation**: Evidence collection and forensics
4. **Risk Analysis**: Determine notification requirements
5. **Notification Prep**: Generate required documents
6. **Regulatory Filing**: Submit to HHS (if 500+ affected)
7. **Remediation**: Prevention and improvement plan

**Includes**:
- Workflow step tracking
- Assignment and deadlines
- Evidence attachments
- Email notifications
- Timeline visualization
- Compliance checklist

### HIPAA Compliance Scoring
- Real-time compliance score (0-100)
- Score breakdown by category:
  - Administrative safeguards
  - Physical safeguards
  - Technical safeguards
  - Breach preparedness
- Trend analysis over time
- Improvement recommendations

- **Zone Types**:

  - DMZ (internet-facing)
  - Cardholder Data Environment (CDE)
- Security level assignment (Low/Medium/High/Critical)

- Cross-zone access control

- Access request workflows
- Session blocking for unauthorized zones

### Cardholder Data Monitoring
- Access logging to CDE
- Suspicious activity detection:
  - After-hours access
  - High-frequency access (>10/hour)
  - Abnormal patterns
  - Failed login attempts
- Real-time alerts
- Session recording for CDE access
- Access audit trail

### Automated Breach Detection
**Detection Rules**:
- Failed login monitoring (>5 failures/15 min)
- After-hours access to CDE
- Unusual data export (>100 MB)
- Cross-zone violations
- Unauthorized zone access
- Geographic anomalies

**Actions**:
- Auto-create security incident
- Severity scoring (Critical/High/Medium/Low)
- Email/SMS alerts
- Investigation panel with evidence
- Containment recommendations

### PCI-DSS Compliance Scoring
- Real-time PCI score (0-100)
- 12 PCI requirement categories
- Quarterly scan scheduling
- Vulnerability detection
- Remediation recommendations
- Compliance reports (QSA-ready)
