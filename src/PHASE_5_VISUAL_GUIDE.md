## Color Palette

### Step States
- **Active**: `#00FF85` (Neon Green)
- **Completed**: `#55D187` (Success Green)
- **Future**: `#374151` (Gray)

### UI Elements
- **Background**: `#0E0E0E` (Dark Midnight)
- **Panels**: `#1C1C1E` (Surface Dark)
- **Borders**: `#00FF85/20` (Green with 20% opacity)
- **Text Primary**: `#FFFFFF` (White)
- **Text Secondary**: `#9CA3AF` (Mist Gray)

### Metric Cards
- **Success**: Green background/5, green border/30
- **Info**: Blue background/5, blue border/30
- **Neutral**: Panel background

## Animation Timing

### Auto-Advance
```
Step 1: 3000ms → Step 2
Step 2: 4000ms → Step 3
Step 3: 5000ms → Step 4
Step 4: 4000ms → Step 5
Step 5: 6000ms → Step 6  ⭐ Longest (KB Article)
Step 6: Manual → Lead Capture
```

### Transitions
- **Step change**: 500ms ease-out
- **Progress bar**: 500ms ease-out
- **Fade in content**: 600ms ease-out
- **Scale effect**: 300ms ease-out

## Accessibility

### Keyboard Navigation
- **Tab**: Navigate through controls
- **Space**: Play/Pause
- **Arrow Left**: Previous step
- **Arrow Right**: Next step
- **Escape**: Close demo

### Screen Reader
- Step progress announced
- Current step title read
- Metrics values read
- Button labels clear

### Focus States
```
Button:focus-visible {
  outline: 2px solid #00FF85;
  outline-offset: 2px;
}
```
